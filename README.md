# video-ip-script-skill

短视频 IP 代运营编导的固定流程技能。把"策划方案书 → 选题 → 呈现方式 → 框架 → 初稿 → 开头 → 润色 → 定稿五件套"固化成一个可复用的工作流，适用于抖音、小红书、视频号等平台的 IP 起号与代运营。

## 目录结构

```
skills/video-ip-script-director/
├── SKILL.md                      # 主流程：10 个阶段、阶段门、协作基线
└── references/
    ├── topic-library.md          # 8 类爆款选题元素、固定句式、适配判断
    ├── formats-frameworks.md     # 12 种呈现方式、7 类文案类型框架
    ├── hooks.md                  # 7 种开头方法、5 秒完播六类钩子
    ├── delivery.md               # 润色洗稿规则、定稿五件套模板、去重台账
    └── shooting-sop.md           # 拍摄 SOP、纪实过程型流程、消费者视角提问库
```

## 安装

**Trae 全局安装（推荐）**

把 `skills/video-ip-script-director` 整个目录复制到：

```
C:\Users\<用户名>\.trae-cn\skills\video-ip-script-director\
```

重启对话后生效，之后在任何项目里都能触发。

**项目内安装**

放到项目根目录：

```
<项目>/.trae/skills/video-ip-script-director/
```

**从 GitHub 安装**

克隆仓库后把 `skills/video-ip-script-director` 复制到上面任一位置即可。技能不依赖脚本和外部服务。

## 怎么调用

技能没有 `/斜杠命令`，靠自然语言触发。说中下面任意一类意图就会自动加载：

- 短视频文案、口播稿、脚本
- 选题、选题库、爆款选题
- 分镜、拍摄模板、拍摄 SOP
- 洗稿、润色、去重、同质化
- IP 起号、代运营、账号策划

如果没自动触发，直接说「用 video-ip-script-director 技能来做」，或者把对应阶段的口令原样发出来。

## 斜杠命令

输入斜杠命令可直接跳到对应阶段，省掉前面的确认环节。命令后的文字就是该阶段输入。

| 命令 | 作用 | 写法示例 |
| --- | --- | --- |
| `/视频建档` | 建档 + 质疑 | `/视频建档 郭郭`，后跟策划方案书 |
| `/视频选题` | 出选题 | `/视频选题 郭郭 对立 成本` |
| `/视频呈现` | 选呈现方式 | `/视频呈现 朋友能力没你强却混得比你好` |
| `/视频拆解` | 拆选题 | `/视频拆解 最没面子的装修风格` |
| `/视频框架` | 只出段落骨架 | `/视频框架 个人故事` |
| `/视频初稿` | 按确认框架出稿 | `/视频初稿 按第二版骨架` |
| `/视频开头` | 开头备选 | `/视频开头 给我 5 个` |
| `/视频润色` | 洗稿 + 时长对齐 | `/视频润色 别和台账重复` |
| `/视频定稿` | 输出五件套 | `/视频定稿` |
| `/视频台账` | 更新档案与台账 | `/视频台账 郭郭` |
| `/视频纪实` | 纪实过程型分支 | `/视频纪实 郭郭 生蚝从进货到上桌` |
| `/视频流程` | 从头连续推进 | `/视频流程 郭郭 成本选题第 3 条` |

这些命令是技能内部的指令层，不是 IDE 命令面板项。输入后由技能识别并进入对应阶段；如果你的客户端不认，直接发命令文字也能生效。

## 各阶段调用口令

| 阶段 | 说什么 | 产出 |
| --- | --- | --- |
| 0 信息建档 | 「这是某某的策划方案书和资料，帮我建档」 | IP 档案 + 质疑清单 |
| 1 选题触发 | 「用头牌、对立、圈人群三类，给某某出选题，每类 10 条」 | 选题清单 + 理由 |
| 2 呈现方式 | 「这个选题适合哪种呈现方式，给理由」 | 1–2 个方式或组合 |
| 3 选题拆解 | 「把这个选题拆一下：人群、冲突、素材、类型」 | 一句话中心选题 + 拆解表 |
| 4 框架确认 | 「按个人故事框架出段落骨架，先别写成稿」 | 段落骨架 + 内容建议 |
| 5 初稿输出 | 「按这个框架出初稿」 | 完整初稿 + 轻量拍摄指引 |
| 6 开头优化 | 「正文定了，给我 5 个开头备选」 | 3–5 个开头 + 钩子组合 |
| 7 逐段润色 | 「按流程逐段润色，时长对齐，别和台账重复」 | 洗稿后的正文 |
| 8 定稿交付 | 「文案润色好了，按流程输出」 | 五件套 |
| 9 记忆更新 | 「把这次的选题和句式记进台账」 | 档案 / 选题库 / 台账更新 |

关键：第 8 阶段只在你明确说「润色好了」「按流程输出」之后才排版五件套。平时不会自动铺开。

## 常用组合示例

**新 IP 从零起号**

```
这是郭郭的策划方案书，先帮我建档，挑出信息缺口和风险
→ 建档完成后：用对立、成本、猎奇三类出选题，每类 10 条
→ 我选第 3 条，分析呈现方式
```

**一条视频走完全流程**

```
选题：为什么你朋友能力没你强却混得比你好（郭郭，南昌，餐饮）
→ 拆解 → 框架确认 → 初稿 → 开头 5 选 1 → 润色 → 按流程输出五件套
```

**纪实过程型（半成品到餐桌）**

```
给郭郭拍食材从半成品到餐桌，走纪实过程型
只要环节清单、口播穿插点、给摄影的引导提问，不用完整台词
```

**老号防重复**

```
出这条文案前先读已定稿台账，相同的句式和观点不要再用
```

## 工作区档案

技能会在当前工作区维护三个目录，跨对话保留上下文：

```
IP档案/<IP名>.md          # 定位、人群、业务、性格、素材、禁区
选题库/<IP名>.md          # 已生成选题及使用状态
已定稿台账/<IP名>.md      # 日期｜选题｜类型｜呈现方式｜开头类型｜已用句式｜已用观点
```

写新稿前先读台账，交付后回写台账。这是防止"炒闲饭"的唯一依据。

## 几条硬规则

- 时长字数和改稿前后偏差不超过 10 秒
- 全篇大白话，60 岁的人能听懂
- 起号期自然堆叠地域关键词（默认南昌，按 IP 替换）
- 不说视频内容兑现不了的承诺
- 已定稿的句式和观点不得复用，同一中心思想必须换角度

## 说明

- 技能不含第三方脚本，纯 Markdown 指令，可自行改词、加选题类型、换地域。
- 想扩展选题类型，改 `references/topic-library.md` 末尾的自定义拓展段；想换交付格式，改 `references/delivery.md` 的五件套模板。
