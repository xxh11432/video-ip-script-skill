# 润色规则与定稿交付

## 一、润色规则

1. 在原文案基础上改，保留中心思想和段落作用，换句式、换角度、换表达做洗稿，规避同质化和查重。
2. 改稿前后字数和时长对齐，视频时长偏差不超过 10 秒。
3. 起号期自然堆叠地域关键词（默认南昌），关键词要落在真实场景里，不硬塞。
4. 检查合理性和适配度：这么说观众信不信、IP 说不说得出口、产品撑不撑得住。
5. 全部改成大白话，不要公司化、商业化表达，60 岁的老奶奶能听懂。
6. 不用形容词堆效果，用具体动作、数字、场景代替。
7. 与已定稿台账逐句比对：出现相同句式或重复观点，必须换角度重写，不能改几个词糊弄。
8. 结尾不喊口号，落在一个具体动作或一句实在话上。

## 二、定稿五件套模板

只有用户确认"文案润色好了"之后，才按下面 1–5 排版输出。

**1. 中心选题**
一句话，能直接当标题用。

**2. 整体框架结构**
段落级骨架，标出每段作用和时长。

**3. 纯文案**
只放正文文字，按段落空行分隔，不带任何思路说明、批注、括号提示，方便直接复制进表格。

**4. 拍摄剪辑模板**

```
① 文案段落框架：段落编号 + 段落作用 + 时长
② 口播内容：逐段台词
③ 拍摄画面补充建议：每个段落配什么画面、机位、景别、动作
④ 剪辑建议：字幕、特效、音效、BGM、画中画、蒙版，逐条给，必须说明和视频调性的适配度，不能突兀违和
⑤ 拍摄建议：IP 的表现力、状态、口吻、动作、节奏
```

所有拍摄相关提示统一用 `【拍摄提示｜红】` 前缀单独成行。导出到 Word 或在线表格时，把这类提示设为红色字体（RGB 255,0,0），方便拍摄现场第一时间找到并照着指导 IP。

**5. 发布简介**
从文案整体内容提炼中心思想写 1–2 句简介，后接 3–5 个 `#话题`，话题包含地域词、行业词、人群词。

## 三、去重与台账规则

已定稿台账按 IP 单独维护，路径 `已定稿台账/<IP名>.md`，每交付一条追加一行：

```
日期｜选题｜文案类型｜呈现方式｜开头类型｜已用核心句式｜已用核心观点
```

- 写新稿前必须先读台账，命中已用句式或观点就换角度。
- 台账只记句式和观点的"中心意思"，不复制全文，避免自己抄自己。
- IP 档案只用来了解人和业务，不能直接把档案里的原话搬进文案。要用自己的话重新总结。

## 四、交付检查清单

- 中心选题是否一句话说清
- 五件套是否齐全，顺序是否正确
- 纯文案是否可直接复制、无多余标注
- 红色拍摄提示是否逐段覆盖
- 时长字数是否对齐，偏差是否在 10 秒内
- 是否与台账重复
- 简介和话题是否齐全
