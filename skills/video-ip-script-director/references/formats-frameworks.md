# 呈现方式与文案框架

## 一、12 种呈现方式

**① 口播讲解式**
对着镜头说话，坐着或站着把想说的直接讲给观众。适合讲知识、讲观点、讲自己的故事。拍摄最快，讲不好就枯燥。

**② 第一视角体验式**
镜头就是 IP 的眼睛，观众跟着往前走、跟着看货、跟着动手。代入感强，适合逛市场、进车间、走流程。

**③ 悬疑偷拍视角**
手机放角落、藏在箱后、架在远处，画面像"不被注意到的真实记录"。适合凌晨工作、同行交流、真实交易，可信度高。

**④ Vlog 纪录视角**
日常记录，按时间线剪出一天。不刻意说教，靠时间线建立信任，适合展示真实工作节奏。

**⑤ 内心 OS**
画面是正常工作，观众听到的是心里在想什么。旁白承担观点输出，容易产生亲近感。

**⑥ 互动问答**
答评论区问题，或拍摄时模拟有人提问。适合连载，评论量高。

**⑦ 吐槽情绪式**
站在用户角度替他们骂、替他们挡坑。情绪要足，容易引发共鸣和评论，注意别变成攻击具体同行。

**⑧ 剧情演绎式**
演自己或演别人，可以一人分饰两角。传播力强，但最费力，需要脚本和表演。

**⑨ 访谈式**
有人拿设备提问，IP 回答，像采访。对话感强，适合挖故事、挖情绪。

**⑩ 演示教学式**
镜头怼手拍，一边操作一边讲。观众学东西，完播率高。

**⑪ 快问快答 / 切片剪辑型**
多个问题快剪，一个问题 15 秒左右，节奏快不拖沓，适合知识类内容。

**⑫ 对比测评式**
好的和差的放一起，让观众自己用眼睛判断。适合讲专业度、讲避坑。

### 选择规则

- 先看选题需要"信任"还是"信息"还是"情绪"，再对应方式。
- 单条视频优先一种主方式，最多加一种辅助。呈现方式超过两种，拍摄执行会失控。
- 组合不做穷举。常见有效组合：口播 + 展示过程、第一视角 + 内心 OS、互动问答 + 吐槽、演示教学 + 对比测评。
- 每次给 1–2 个方案，写明适配理由、拍摄成本、风险，让用户拍板后再往下走。
- 没拿到选题、文案类型或框架之前，不提前做组合。

## 二、7 类文案类型框架

### 1 置顶创业故事（情感共鸣）

骨架：起点 → 转折事件 → 决定性的投入 → 现在的结果 → 一句人话感悟。
用途：新号置顶，让人快速认识这个人。注意别写成成功学，要具体到某一天、某一笔钱、某一个客户。

### 2 个人故事（人设建立信任）

骨架：一个具体场景 → 当时的处境和选择 → 付出的代价 → 得到的东西 → 现在怎么做事。
注意：细节代替形容词。"凌晨三点去市场"比"我很努力"有说服力。

### 3 有用的知识分享型（解决实际需求）

骨架：先给结论 → 为什么 → 怎么做（分步骤）→ 常见误区 → 一句提醒。
注意：必须能落地，宁可少讲两个点，也不要讲得对但没用。

### 4 展示过程（展示专业 + 解压体验）

骨架：今天要做一件什么事 → 关键环节（3–5 个）→ 中途遇到的意外或判断 → 成品呈现 → 一句轻收尾。
注意：过程要真实、有声音、有手感。不要配大段说教。

### 5 案例展示（行业背书 + 人设靠谱）

骨架：客户是谁、什么需求 → 我们怎么判断 → 中间怎么调整 → 结果 → 客户说了什么。
注意：客户信息脱敏，结果要真实，不能承诺"谁做都有效"。

### 6 蹭热点型（追潮流 + 借势引流）

骨架：热点是什么 → 这个热点和我的行业有什么关系 → 我的观点或做法 → 落到自己的业务。
注意：只蹭和业务有关的，硬蹭会稀释人设。

### 7 互动挑战型（引发参与 + 传播）

骨架：抛出一个挑战或标准 → 我先做示范 → 邀请观众参与 → 留一个可讨论的钩子。
注意：挑战门槛要低，观众能当场参与。

## 三、通用故事框架

以前（以前是个什么样的人、过什么样的生活）+ 困难（直到什么事发生让你觉得必须改变）+ 改变（下了什么血本做了一件什么事）+ 现在（案例背书和信任成交）+ 感悟（成功没有捷径，只有真诚待人，把好的产品和好的服务给到客户）

括号里要写具体内容点，不要停在抽象词。用户没有 IP 个人信息、只给选题时，框架内只给概念和内容建议，不编造细节。

## 四、框架输出格式

```
文案类型：<类型名>    呈现方式：<方式或组合>    预估时长：<秒>
段落 1｜作用：<这一段要解决什么>｜内容建议：<放什么素材、什么观点>
段落 2｜...
段落 N｜...
收尾｜作用：<引导动作或情绪落点>
```

框架阶段不写成稿，不写台词。等用户确认骨架后再进初稿。
