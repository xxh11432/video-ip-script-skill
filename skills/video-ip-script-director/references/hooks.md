# 开头与 5 秒完播钩子

## 三种底线认知

1. 开头的目的不是骗点击，是让目标观众在 3 秒内意识到"这条视频跟我有关"。
2. 先过相关性过滤器：这个开头吸引来的人，是不是我想要的目标受众。吸引所有人不如精准过滤。
3. 不给视频内容兑现不了的承诺。宁可降低期待、超额交付，也不要拉高期待、让人失望。

## 七种开头方法

### 第一种 内容预告
一句话概括本条视频最核心的看点。
适用：内容本身有稀缺性；内容平淡时，把最精彩片段前置当预告。
案例："四个女生和一个大叔，去网吧的一天""和你的大学同学是一个 54 岁的阿姨，是一种怎样的体验"

### 第二种 价值悬念
告诉观众会分享一个有用的方法，但只点到为止。
与旧写法的区别：不说"看完你就能做到某某"，而说"我有个方法和大多数人不一样"。
案例对比：旧写法"看完这条视频，你就能无痛把烟戒掉"有失信风险；新写法"我最推荐的戒烟方法，和 90% 的人想得都不一样"容错更高。
更多案例："为了让大家多喝水，我们把茶水吧改成了游戏厅""我用了这个方法以后，第一次觉得减肥可以不那么痛苦"

### 第三种 现象牵制
描述一个普遍行为或状态，让观众觉得"这不就是我吗"。
侧重行为共鸣，问的是"你也是这样吗"。
案例："每次出差放假回家，行李箱就一直躺在房间里，根本不愿意收拾""睡醒就刷短视频，吃东西无节制，每天只想摆烂"

### 第四种 事件开场
开头直接交代发生了一件事，用意外性激发好奇。
前提：事件必须有冲突，否则就是流水账。特别适合 vlog。
案例："那天我出了车祸""那天我偷了别人的橙子，被果农抓个正着"

### 第五种 话题开场
抛一个开放性、可讨论的话题，给观众留参与空间。
侧重观点参与，问的是"你怎么看这件事"。作用是避免视频变成自说自话。
案例："一个普通人怎样才能做到年入 30 万，而且是从零开始""你嫉妒过自己的朋友吗"

### 第六种 喊话观众
开头直接点名某一类人，或直接发问、发起挑战。
原理：大多数人刷视频不主动思考，需要被"喊"一下才进入互动状态，有利于培养粘性。
案例："如果你今年跟我一样，三十几岁还没有结婚的话""给你三秒钟时间想一下，怎么在抖音上卖鸡，3、2、1"

### 第七种 直击痛点
直接指出目标人群正在烦恼的具体问题，让人感到"这条视频对我有用"。
侧重负面问题的解决方案，信号是"你有这个问题，而我有答案"。垂类账号尤其有效，能筛出有消费意愿的人。
案例："为什么你朋友能力没你强，却混得比你好""娃子啥都想要，不买就在地上哭，真的是太奢侈了"

## 5 秒完播的六类钩子

| 类型 | 做法 | 注意 |
| --- | --- | --- |
| 画面钩子 | 反常画面、强对比、成品前置、动作特写 | 第一帧要能看懂在干什么 |
| 文案钩子 | 前 3 句出现冲突、数字、身份反差 | 不堆形容词，一句话一个信息 |
| 音效钩子 | 现场声、开门声、刀落案板、市场嘈杂 | 声音要和画面同步，不能贴错 |
| 音乐钩子 | 前奏抓耳、卡点进正题 | 调性匹配，不要为热闹而热闹 |
| 文字钩子 | 屏幕大字、关键词高亮 | 字数控制在 8 字内，放安全区 |
| 特效钩子 | 转场、速度变化、局部放大 | 服务内容，不能盖过画面 |

## 输出格式

```
【开头备选 1｜类型：内容预告】<文案>
钩子组合：画面 + 文字；适配理由：<为什么适合这条选题和这个 IP>
...
【推荐】备选 N，理由：<一句>
```

给 3–5 个备选，类型不重复。开头只在正文定稿后打磨，顺序不能提前。
