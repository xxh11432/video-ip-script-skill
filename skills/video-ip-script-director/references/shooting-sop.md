# 拍摄 SOP 与引导提问

## 一、拍摄 SOP 的目标

把定稿文案交给任何一个小白拍摄，都能看懂该怎么拍。前提是不破坏整篇文案的整洁度，一眼扫过去就知道每个段落拍什么。

## 二、排版原则

- 按段落编号，一段一个区块，段落之间留空行。
- 每个区块固定三行结构：口播内容 / 画面建议 / 拍摄提示（红）。
- 拍摄提示不塞进台词里，永远独立成行并加 `【拍摄提示｜红】` 前缀。
- 需要多机位或补拍的段落单独标注，不让拍摄人员自己猜。
- 全篇最后附一张"必拍镜头清单"，按场景归并，避免重复跑位。

## 三、现场执行 SOP

开机前：

1. 对一遍必拍镜头清单，确认场地、道具、人物到位。
2. 检查光线方向、收音设备、服装和背景，背景不要出现杂乱商标。
3. 手机横竖屏、分辨率、帧率统一设定，中途不改。

拍摄中：

1. 每段口播至少拍两遍，保留完整收音，不要边拍边剪。
2. 每段结束补 3–5 秒空镜和手部特写，给剪辑留余量。
3. 只按文案结构拍，不擅自加词改词；IP 临场发挥好的句子单独记录，交给编导判断是否保留。
4. 现场声音（刀声、水声、市场声）单独录一段干净素材。

收尾：

1. 素材按"日期-IP-段落号"命名，当天备份。
2. 拍完核对必拍镜头清单，缺的当场补。
3. 现场记一条拍摄备注：哪段没拍好、哪句情绪不对，交给剪辑和编导。

## 四、纪实过程型拍摄（半成品到餐桌）

这类视频不需要完整定制台词，只给框架，让 IP 自己发挥，但要穿插口播，不能拍成纯过程。

输出三样东西：

1. **环节清单**：按时间顺序列每个环节，写清拍什么、大概时长、机位和景别。
2. **口播穿插点**：标出 2–3 个必须停下来讲两句的位置，例如处理食材时、上桌前、收尾时。
3. **引导提问**：给拍摄人员一组问题，现场自然问出来，让 IP 自己回答。拍摄人员不背稿，只负责把问题问出去、把回答录完整。

引导技巧：

- 用"为什么、如果、最"开头提问，不用"你能不能介绍一下"这类空问题。
- IP 答完追问一句"那会怎么样""不这样会怎样"，逼出细节。
- 允许说错、允许停顿，真实比流畅重要。
- 不问需要背数据的问题，问他自己做过的事。

## 五、消费者视角引导提问库

按消费者真正关心的维度分组。每组给出提问和理由，拍摄时按 IP 和行业挑选，不要一次全问。

**品质与新鲜**

- "这批和那批差在哪，你一眼怎么看出来的？" 理由：消费者最怕买亏，看得见的判断标准最能建立专业感。
- "为什么这个贵，那个便宜？" 理由：把价格差异讲成品质差异，比直接报价更有说服力。

**工艺与做法**

- "这一步为什么必须这么做？少做会怎么样？" 理由：工艺细节是过程型视频的情绪支点，也最容易拍出画面。
- "你做这东西，最费时间的是哪一步？" 理由：让观众感知成本，自然理解价格。

**成本与价格**

- "这一份成本大概在哪个范围？" 理由：敢谈成本的人显得坦荡，但要提醒 IP 只谈区间，不谈底价。
- "为什么卖这个价，值在哪？" 理由：把价格翻译成价值，减少比价流失。

**选择与避坑**

- "顾客自己来买，最容易踩什么坑？" 理由：站在消费者一边说话，评论互动最好。
- "怎么一眼看出好坏，教我一个最简单的办法。" 理由：给一个可带走的判断方法，观众愿意收藏转发。

**场景与使用**

- "买回去怎么保存，放几天还能吃？" 理由：使用场景问题是真需求，能带来精准咨询。
- "一家三口买多少合适？" 理由：把产品换算成生活单位，降低决策门槛。

**售后与信任**

- "东西出问题你一般怎么处理？" 理由：敢讲售后的人可信，能消掉最大顾虑。
- "做了这么多年，有没有返工或者砸掉重做的时候？" 理由：真实的失误比完美的自夸更可信。

**人物与坚持**

- "每天这么早起来，图什么？" 理由：情绪落点，给视频一个有人味的收尾。
- "有没有想过不干了？" 理由：反差回答容易出金句，但要提醒 IP 别演，真实说。

提问只作引导，最终用哪几句、怎么剪，由编导按文案调性决定。回答里出现和文案观点冲突的内容，先标记出来给用户判断，不要直接剪进去。
