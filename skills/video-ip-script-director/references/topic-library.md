# 选题库：8 类爆款选题元素

## 生成规则

- 8 类是思路，不是定式。用户指定元素时每类出 10 条；未指定时先挑 3 类最适配当前 IP 的，每类 5 条。
- 每条选题必须同时满足：能拍、和 IP 有关、有冲突或利益点。硬凑的选题不给。
- 固定句式只是起点，允许跳出句式，只要围绕该元素的底层逻辑。
- 必须做思维拓展，主动补充句式外的新选题类型，写清新的句式和使用条件。
- 输出表头固定为：编号｜选题｜借用的句式｜生成理由｜建议文案类型｜建议呈现方式。
- 每条都要给"为什么这么出"的理由，供用户一起优化，不能只给标题列表。

## 1 头牌选题

固定句式：

1. 世界上最贵的东西到底有多贵
2. 明星的东西到底值多少钱
3. 最牛的人到底有多牛
4. 最贵的东西到底好在哪

用法：把行业头部人物、顶级产品、极端价格代入句式。
示例：汽车行业 → 周杰伦家车库里的车到底值多少钱；医美行业 → 世界上整容花费最多的人花了多少钱。

## 2 怀旧选题

固定句式：

1. 20 年前经典的什么什么
2. 古代人是如何办到的
3. 小时候那些难忘的什么
4. 当年最火的什么
5. 曾经那些价值不菲的什么

示例：母婴 → 古代人是怎么剖腹产的；女装 → 80 年代最流行的港风。

## 3 对立选题

固定句式：

1. 穷人 vs 富人
2. 南方人 vs 北方人
3. 男人 vs 女人
4. 中国人 vs 外国人
5. 古代 vs 现代
6. 有良心的 vs 没良心的
7. 曾经 vs 现在

示例：烧烤 → 北方人吃烧烤和南方人吃烧烤有什么区别；教培 → 穷人家的孩子与富人家的孩子上课外班的区别。

## 4 最差选题

词汇池：贬值最快的、最难吃的、差评最多的、最难看的、最没面子的、拼多多 9 块 9 的、最难用的、反人类设计的。

规则：把词汇加到行业或产品上，必须靠谱，不强行硬加。负面词要落在"帮用户避坑"的立场上，不能变成攻击同行。
示例：装修 → 贬值最快的家具；最没面子的装修风格。

## 5 荷尔蒙选题

固定句式：

1. 相亲成功率高的
2. 异性多看你两眼
3. 最具有性缩力的
4. 一秒下头的
5. 自以为很帅、很漂亮、很好，实际对方眼里很丑很差
6. 去丈母娘家能先动筷的
7. 必跟闺蜜、哥们吐槽的

示例：穿搭 → 这样穿，女生在大街上会多看你两眼；健身 → 男生练哪里，越练女生越讨厌。

## 6 猎奇选题

固定句式：

1. 脑回路有病的
2. 外行人绝对不知道的
3. 黑心内幕操作的
4. 内行人的神奇操作
5. 匪夷所思的行为

规则：可以完全抛开句式，只要围绕猎奇。内幕类必须能落到真实素材，不能编造。

## 7 圈人群选题

固定句式：

1. 按星座的
2. 内向或外向的
3. 不同 MBTI 的
4. 身价十个亿的
5. 第一次体验的
6. 弱势群体的

示例：母婴 → 巨蟹座的妈妈带孩子有哪些麻烦、刚生完宝宝的妈妈会有哪些焦虑、身价十个亿的妈妈是怎么带孩子的。

## 8 成本选题

词根：

1. 便宜又有面子的
2. 十分之一金钱就能完成的
3. 十分之一时间就能完成的
4. 薅羊毛还能保持体面的
5. 某某如何偷懒
6. 如何贪小便宜
7. 花超大钱这个事会怎么办
8. 花小钱办大事

底层逻辑：金钱、时间、面子、力气，都是人爱看的成本。
示例：母婴 → 如何让爸爸帮忙夜里看孩子；摄影 → 逛街拍照，找这三个建筑物就肯定好看。

## 选题适配判断

拿到用户给的选题时，先过四道判断：

1. 人群是否明确，能不能一句话说清"拍给谁看"
2. 是否有冲突、反差或明确利益点
3. 现有素材是否拍得出来，拍摄成本是否可接受
4. 和 IP 定位、变现路径是否一致

判断通过后再推荐文案类型和呈现方式，理由要具体到这条选题，不能套模板话术。

## 自定义拓展示例

- 反常识：「越贵的东西反而越不好用」
- 结果倒推：「他靠这个笨办法，三年开了四家店」
- 身份反差：「开着百万车的人，来我这儿只点最便宜的」
- 行业内幕：「商家最不想让你知道的三件事」

新增类型时，写清句式模板、适用行业、注意事项，追加到本文件。
